# FLOW

FLOW is a modern productivity workspace designed to help you organize tasks, manage projects, and track your progress in one simple place.

## Features

- User registration and login
- Supabase authentication
- Personal projects
- Task management
- Task completion tracking
- Project progress tracking
- Search and task filtering
- Dark and light mode
- Responsive design for desktop, tablet, and mobile
- Personal data isolation through Supabase Row Level Security

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Supabase
- Lucide React
- CSS
